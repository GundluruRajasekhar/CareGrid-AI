# CareGrid-AI
A privacy-first, fully offline health guardian built from nine cooperating rule-based agents. No API key, no server, no account.

> **100% local processing. No health data leaves your device.**

## Run
Open `index.html` in a browser, or host the folder (GitHub Pages / Vercel) and use "Add to Home Screen". An inline web-app manifest is included; a service worker (`sw.js`) is listed in tasks.md as the next step for guaranteed offline install.

## Multi-agent architecture
Risk, Medication, Nutrition, Fitness, Emergency, Report, Symptom, Wellness and Coach agents each own a set of rules. Every alert shows which agent produced it, the dashboard shows each agent's status, and the Agent Activity panel logs who said what.

## Features
- Future risk projection: what-if simulator (BP, BMI, adherence, glucose, smoking) showing projected score changes
- Coach insight: trend-based sentence linking BP change and medication adherence change
- Weekly health report: week-over-week weight, BP, glucose, heart rate, adherence, overall trend; print or copy
- Explainable risk score: each factor shows its points (for example "BP 160/100 (+28)") plus a recommendation and timeframe
- Health digital twin: profile, 30-day comparison ("cardiovascular risk has increased by N%"), vitals trends
- AI health coach: daily goals, weekly targets, weekly summary (generated by local rules)
- Report analyser: abnormal values, interpretation, change versus previous report, follow-up recommendations
- Emergency intelligence: banner picks the right guide (cardiac, stroke, heat stroke, diabetic) from the readings
- BMI, BP analyser, symptom checker, medicine adherence alerts, trend charts, history, JSON export

## Honest limits
Decisions are explicit if-then rules, not a language model. No free-form reasoning, no PDF/photo OCR, no wearable integrations. The emergency banner appears for BP 180/120 or higher, SpO2 below 92, glucose below 70 or 300 and above, and temperature 40 C or higher.

## Future (Google AI)
The agent design supports later integration of Gemini API, Gemini Live and Gemma for advanced reasoning and conversational healthcare. Each agent would call a model while keeping the local rules as a safe fallback.
